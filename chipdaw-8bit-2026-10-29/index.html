ヘルプ / キー操作 / JSON スキーマ
手で編集
  • ピアノロール: クリックで置く → そのまま横ドラッグで長さ。ノートをドラッグで移動、右端ドラッグで長さ。右クリック/ダブルクリック/⌫ツールで削除。
  • キー: Space 曲再生/停止 · Shift+Space パターンループ · z〜m/q〜i 鍵盤（ステップ入力ON で書き込み）· -/= オクターブ
  • 選択ノート: ←→ 移動 · ↑↓ 半音（Shift でオクターブ）· [] 長さ · Del 削除 · Ctrl+Z 取り消し
  • レーン表示（ロール上の4段）をクリックでチャンネル切替。M=ミュート S=ソロ。
  • ノート fx: arp=アルペジオ（16進の半音列 例 037）、slide=半音スライド。Noise ch の音程は 0〜15（NES の周期番号、0 が最も高い）。
AI（ローカル）
  • プロンプトのキーワード（廃墟/探索/戦闘/クリア/明るい/和風/宇宙/速い/遅い、BPM・調・小節数）からムードを決め、和声進行→モチーフ反復メロ→ハモ/アルペジオ→ベース→ノイズドラムをシード付き乱数で組み立てる。
  • 「効果音/SE」やジャンプ・宝箱・ダメージ等の語なら SFX パラメータを生成してサンドボックスに入れる。
  • 生成結果は全部ふつうのノートなので、そのまま手で直せる。クラウド LLM ではない（オフラインでも動く）。

  meta:{root:57, scale:'minor'},
  instruments:[{name, wave:'pulse'|'tri'|'saw'|'noise',
    duty:.125|.25|.5|.75, vol, a,d,s,r, vib, vibRate,
    vibDelay, slide, arp:'047', noiseMode:'long'|'short'}],
  channels:[{name, inst}],           // 4ch
  patterns:[{name, ch:[[cell|null × rows] × 4]}],
  order:[0,1,0,2] }
cell = { n:MIDI(Noise:0-15), l:行数, v:1-15,
         i?:音色上書き, fx?:{arp:'037', slide:12} }
