オーディオ書き出し（WAV / MP3）

ループ用はゲームのBGMループ向け。長さはパターン／曲の正確な周期。はみ出した余韻・エコーは頭に折り返して重ねるので、継ぎ目でプツッとしない（ゲーム側でそのままループ再生すればOK）。ゲーム用ループは WAV 推奨（MP3 は仕様上、先頭にエンコーダ遅延の無音が入りわずかに隙間が出ることがある）。

編集は自動保存（localStorage）。ゲーム曲は ?song=ruins / guardian / dawn で開ける（ゲーム本体には反映されない）。

音源エンジン: /audio/chip.js（ゲームと共通）· ゲーム: 廃墟の灯火 · x-bm-demos 一覧

手で編集

  • ピアノロール: クリックで置く → そのまま横ドラッグで長さ。ノートをドラッグで移動、右端ドラッグで長さ。右クリック/ダブルクリック/⌫ツールで削除。
  • Space 曲再生/停止 · Shift+Space パターンループ · z〜m/q〜i 鍵盤（ステップ入力ON で書き込み）· -/= オクターブ
  • 選択ノート: ←→ 移動 · ↑↓ 半音（Shift でオクターブ）· [] 長さ · Del 削除 · Ctrl+Z 取り消し
  • ロール上の4段レーンをクリックでチャンネル切替。M/S は「曲」タブ。
  • ノート fx: arp=アルペジオ（16進の半音列 例 037）、slide=半音スライド。Noise ch の音程は 0〜15（0 が最も高い）。

AI（ローカル）

  • キーワード（廃墟/探索/戦闘/クリア/明るい/和風/宇宙/速い/遅い、BPM・調・小節数）からムードを決め、和声進行→モチーフ反復メロ→ハモ/アルペジオ→ベース→ノイズドラムをシード付き乱数で組み立てる。
  • 「効果音/SE」やジャンプ・宝箱・ダメージ等の語なら SFX を生成して「効果音」タブに入れる。
  • ループBGM向け: 「ループBGM 探索 2小節」などで生成 → 「入出力」で 範囲=現在のパターン or 曲全体、モード=ループ用 で書き出すと、ゲームでそのままループできる1周期ぶんの WAV/MP3 になる。
  • 生成結果は全部ふつうのノート。クラウド LLM ではない（オフラインでも動く）。
Song JSON v1 スキーマ
{ v:1, title, bpm, rpb:4, rows:32, swing, echo,
  meta:{root:57, scale:'minor'},
  instruments:[{name, wave:'pulse'|'tri'|'saw'|'noise',
    duty:.125|.25|.5|.75, vol, a,d,s,r, vib, vibRate,
    vibDelay, slide, arp:'047', noiseMode:'long'|'short'}],
  channels:[{name, inst}],           // 4ch
  patterns:[{name, ch:[[cell|null × rows] × 4]}],
  order:[0,1,0,2] }
cell = { n:MIDI(Noise:0-15), l:行数, v:1-15,
         i?:音色上書き, fx?:{arp:'037', slide:12} }
